    컨베이어 카드¶

    벨트 출발·정지·속도 제어 카드들입니다.

    무엇을 하는 단계인가요?¶

    컨베이어 벨트의 회전·정지·속도를 제어합니다. 보통 센서 카드와 함께 사용해서 물체가 감지되면 벨트가 멈추는 흐름을 만듭니다.

    카드 종류¶

    • 벨트 동작

      컨베이어 켜기 · 컨베이어 끄기

      벨트 회전 시작 / 정지

    • 속도 제어

      컨베이어 속도

      1단계 (느림) ~ 3단계 (빠름)

    • 타이머

      N초 후 꺼짐

      이전 출력 (컨베이어/GPIO/조명/배경음/그리퍼) 자동 OFF

    카드별 사용법¶

    컨베이어 켜기¶

    벨트 회전을 시작합니다.

    • 파라미터: 방향 (정방향 / 역방향, 기본 정방향)
    • 사용: 흐름의 적절한 시점에 배치

    자동 정지 없음

    컨베이어 켜기 카드는 방향만 지정 합니다. 정지 시점은 사용자가 [센서 감지 대기] + [컨베이어 끄기] 카드로 명시해야 합니다.

    컨베이어 끄기¶

    벨트 회전을 즉시 정지합니다.

    • 파라미터: 없음
    • 사용: 정지가 필요한 시점에 명시적 배치

    컨베이어 속도¶

    벨트 회전 속도를 설정합니다.

    단계 의미
    1단계 느림
    2단계 보통 (기본)
    3단계 빠름

    속도 카드는 켜기 카드 이전에

    [컨베이어 속도] → [컨베이어 켜기] 순서로 배치하면 명확합니다. 속도 변경은 흐름 중간에도 가능합니다.

    N초 후 꺼짐 (타이머 자동 OFF)¶

    이전에 켠 출력 (컨베이어, GPIO, 카메라 조명, 배경음, 그리퍼) 을 N초 후 자동으로 끄는 카드입니다.

    • 파라미터:
      • 지연 시간 (초, 0.1 ~ 30, 기본 3)
      • 꺼질 대상 (드롭다운):
        • 컨베이어 끄기 (기본)
        • GPIO 출력 끄기
        • 카메라 조명 끄기
        • 배경음 정지
        • 그리퍼 열기

    타이머 활용 패턴

    [켜기 카드] → [N초 후 꺼짐] 패턴으로 별도의 [끄기 카드] 를 흐름에 명시적으로 두지 않아도 됩니다. 간결한 흐름 작성에 유용.

    컨베이어 켜기
  ↓
N초 후 꺼짐 (5초, 컨베이어 끄기)   ← 5초 후 자동으로 컨베이어 정지
  ↓
[다음 카드들이 즉시 진행됨]        ← N초 대기하지 않고 바로 다음으로

    N초 후 꺼짐 vs N초 기다리기

    • N초 후 꺼짐 — 흐름이 멈추지 않음. 백그라운드에서 N초 후 자동 OFF.
    • N초 기다리기 (기본 카드) — 흐름이 N초간 멈춤.

    두 카드의 동작이 완전히 다르므로 의도에 맞게 선택하세요.

    사용 예시¶

    예시 1 — 가장 단순한 흐름

    시작
  ↓
컨베이어 속도 (2단계)
  ↓
컨베이어 켜기 (정방향)
  ↓
5초 기다리기
  ↓
컨베이어 끄기
  ↓
종료

    벨트 보통 속도로 회전 → 5초 후 정지

    예시 2 — 센서 감지 후 정지 (가장 흔한 패턴)

    시작
  ↓
컨베이어 켜기
  ↓
센서 감지 대기 (IR1, 30초)   ← 물체 감지될 때까지 대기
  ↓
컨베이어 끄기                 ← 감지되자마자 정지
  ↓
[로봇이 물체 처리]
  ↓
종료

    예시 3 — 타이머로 자동 정지

    시작
  ↓
컨베이어 켜기
  ↓
N초 후 꺼짐 (5초, 컨베이어 끄기)   ← 5초 후 자동 정지
  ↓
메시지 보내기 ("벨트 5초 동작")     ← 즉시 다음 카드 진행
  ↓
종료

    [컨베이어 끄기] 카드를 명시할 필요가 없어 흐름이 간결해집니다.

    예시 4 — 속도 변경

    시작
  ↓
컨베이어 속도 (3단계)         ← 빠르게
  ↓
컨베이어 켜기
  ↓
센서 감지 대기 (IR1)
  ↓
컨베이어 속도 (1단계)         ← 정밀 위치 조정용 느리게
  ↓
1초 기다리기
  ↓
컨베이어 끄기
  ↓
종료

    자주 발생하는 문제¶

    벨트가 자동으로 안 멈춤

    의도된 동작입니다. 컨베이어 끄기 카드를 명시적으로 배치해야 정지합니다. 보통 [센서 감지 대기] 후에 배치합니다.

    속도 설정이 적용 안 됨

    [컨베이어 속도] 카드를 [컨베이어 켜기] 이전에 배치했는지 확인. 동작 중 변경도 가능하지만 카드 순서가 중요합니다.

    벨트 방향이 의도와 반대

    [컨베이어 켜기] 카드의 방향 파라미터를 정방향 / 역방향 으로 변경. 키트 설치 방향에 따라 다를 수 있습니다.

    벨트가 아예 안 돌아감
    1. [장비] 탭의 메인보드 상태가 "● 연결됨" 인지 확인
    2. 메인보드 전원 어댑터가 콘센트에 정상 연결됐는지 확인
    3. 컨베이어 위에 장애물이 있는지 확인

    강사 팁¶

    컨베이어 + 센서 조합이 가장 흔함

    사용 예시 2 의 "컨베이어 켜기 → 센서 감지 → 컨베이어 끄기" 패턴이 가장 자주 사용됩니다. 학생에게 이 3카드 조합을 먼저 가르치세요.

    안전 — 종료 전 반드시 끄기

    흐름 종료 직전에 [컨베이어 끄기] 카드를 배치하는 것을 습관화하세요. 끄기 카드 없이 종료하면 벨트가 계속 돌 수 있습니다.

    느린 속도가 학습에 좋음

    학생이 컨베이어 동작을 관찰할 때는 1~2단계 권장. 빠른 속도는 시각 추적이 어려워 학습 효과가 떨어집니다.

    다음 단계¶

    컨베이어 카드에 익숙해졌다면 센서 카드 → 로 이동합니다.
