    기본 카드¶

    모든 흐름의 기초가 되는 카드들입니다. 시작·종료, 대기, 메시지/음성, 음악 카드를 다룹니다.

    무엇을 하는 단계인가요?¶

    가장 단순한 흐름을 만드는 데 필요한 카드들을 익힙니다. 첫 학습에서는 시작 → 메시지 → 종료 만 사용해도 충분합니다.

    카드 종류¶

    • 흐름 제어

      시작 · 종료 · N초 기다리기

      프로그램의 시작·종료와 시간 대기

    • 메시지·음성

      메시지 보내기 · 말하기 · 효과음

      화면 표시·TTS·짧은 음향

    • 배경음

      배경음 시작 · 배경음 정지

      잔잔하거나 신나는 음악 반복 재생

    카드별 사용법¶

    시작 / 종료¶

    카드 파라미터 사용 위치
    시작 없음 모든 흐름의 첫 카드
    종료 없음 흐름의 마지막 카드

    시작 카드 누락 주의

    모든 흐름은 반드시 시작 카드로 시작해야 합니다. 누락 시 실행 오류가 발생합니다.

    N초 기다리기 (대기 카드)¶

    지정한 시간만큼 다음 카드 실행을 미룹니다.

    • 파라미터: 시간 (초) — 0.1초 ~ 30초, 기본값 3초
    • 사용 예시: "벨트 켜기 → 3초 기다리기 → 벨트 끄기"

    E-STOP 시 즉시 취소

    대기 중에도 [비상 정지] 버튼을 누르면 즉시 중단됩니다.

    메시지 보내기¶

    화면의 메시지 보드에 텍스트를 표시합니다.

    • 파라미터:
      • 메시지 내용 (텍스트)
      • 크기 (작게 / 보통 / 크게)
    • 변수 삽입: {변수이름} 형식으로 런타임 변수값 자동 표시
    • 예시: "색상: {감지색상}" → "색상: 빨강" 으로 표시됨

    변수 삽입 활용

    카메라로 색상을 감지한 후 "색상은 {감지색상}입니다" 처럼 표시하면 학생이 결과를 즉시 확인할 수 있습니다.

    말하기 (TTS)¶

    텍스트를 음성으로 읽어줍니다 (한국어 기본).

    • 파라미터:
      • 내용 (텍스트, 변수 삽입 가능)
      • 속도 (느리게 / 보통 / 빠르게)
    • 예시: "작업이 완료되었습니다"

    효과음¶

    짧은 음향 신호를 재생합니다.

    • 옵션: 삐 (beep) / 성공 / 오류 / 알림 / 완료
    • 사용: 단계 전환·성공·실패 알림에 사용

    배경음 시작 / 정지¶

    반복 재생되는 배경 음악을 제어합니다.

    카드 파라미터 의미
    배경음 시작 곡 (잔잔한 / 신나는), 볼륨 (3 / 5 / 8 / 10) 음악 시작, 다른 카드와 병렬
    배경음 정지 없음 음악 정지

    배경음과 효과음 동시 재생 가능

    배경음 (반복) 과 효과음 (일회) 은 독립적으로 작동하므로 동시 재생 가능합니다.

    사용 예시¶

    예시 1 — 가장 단순한 흐름

    시작
  ↓
메시지 보내기 ("안녕하세요")
  ↓
3초 기다리기
  ↓
종료

    화면에 "안녕하세요" 표시 → 3초 후 흐름 종료

    예시 2 — 음성 안내

    시작
  ↓
말하기 ("작업을 시작합니다")
  ↓
[실제 작업 카드들]
  ↓
효과음 (완료)
  ↓
말하기 ("작업이 끝났습니다")
  ↓
종료

    예시 3 — 배경음과 작업

    시작
  ↓
배경음 시작 (잔잔한, 볼륨 5)
  ↓
[작업 카드들]
  ↓
배경음 정지
  ↓
종료

    자주 발생하는 문제¶

    메시지가 화면에 안 보임
    1. 메시지 보드가 화면 우측 패널에 보이는지 확인
    2. 메시지 크기를 "크게" 로 설정하면 더 잘 보임
    3. 패널이 접혀 있다면 패널 헤더 클릭하여 펼치기
    말하기 카드에서 변수값이 표시 안 됨

    {변수이름} 처럼 중괄호로 변수명을 감싸야 합니다. 예: "색상은 {감지색상}입니다"

    시작 카드 없이 실행하면?

    파싱 오류 발생. 흐름은 항상 시작 카드로 시작해야 합니다.

    강사 팁¶

    첫 학습은 단순 흐름부터

    학생의 첫 흐름은 시작 → 메시지 보내기 → 종료 3개 카드만으로 충분합니다. 동작 확인 후 점차 카드를 늘려가세요.

    TTS 발음 확인

    말하기 카드에 영어가 섞이면 발음이 어색할 수 있습니다. 한글 위주로 문장 작성 권장.

    효과음으로 단계 구분

    긴 흐름에서는 단계마다 효과음 (성공/완료) 을 넣어두면 학생이 진행 상황을 청각으로 파악할 수 있습니다.

    다음 단계¶

    기본 카드에 익숙해졌다면 로봇 제어 카드 → 로 이동합니다.
