    프리모블록¶

    프리모블록은 카드를 위에서 아래로 끌어 놓아 자동화 흐름을 만드는 시각 코딩 환경입니다. 각 카드는 PLC 의 한 동작에 대응하며, 위에서 아래로 순서대로 실행됩니다.

    카드 종류¶

    • 기본 카드

      시작/종료, 대기, 메시지 출력

      기본 카드

    • 로봇 제어 카드

      이동, 그리퍼, 위치 교시 사용 (Lite 6)

      로봇 제어 카드

    • 컨베이어 카드

      벨트 출발/정지, 속도 제어

      컨베이어 카드

    • 센서 카드

      IR 센서 대기, 카메라 색상 인식

      센서 카드

    • GPIO 카드

      외부 버튼 입력, 출력 제어, 아날로그 신호

      GPIO 카드

    • MQTT 카드

      여러 키트 간 메시지 통신, 협업 자동화

      MQTT 카드

    • 변수 · 조건 · 반복

      VAR, IF, LOOP 카드

      변수 · 조건 · 반복

    • 병렬 실행

      여러 동작을 동시에 실행

      병렬 실행

    • 이벤트 감시

      백그라운드에서 GPIO/MQTT/센서 자동 감시

      이벤트 감시

    • 나만의 블록 (서브루틴)

      자주 쓰는 동작을 묶어 재사용 (FB 개념)

      나만의 블록

    • AI 비전 카드

      AI 비전 스튜디오에서 학습한 모델로 분류·판별·카운팅

      AI 비전 카드

    첫 학습 자료¶

    • 첫 프로그램 만들기

      컨베이어 + 로봇 + 카메라 통합 예제로 단계별 흐름 학습

      첫 프로그램 만들기

    • ST 코드 보기

      프리모블록을 IEC 61131-3 ST 코드로 자동 변환하여 산업용 PLC 와 호환

      ST 코드 보기

    프리모블록의 특징¶

    • 위 → 아래 순차 실행 — PLC 스캔 사이클과 1:1 매칭
    • 카드 ↔ ST 코드 양방향 변환 — 산업용 PLC 코드로 그대로 내보내기 가능
    • 블록 스코프 시각화 — IF / LOOP 의 들여쓰기로 코드 구조가 한눈에

    프리모블록 vs 프리모노드¶

    구분 프리모블록 (이 메뉴얼) 프리모노드
    배치 위 → 아래 순차 자유 캔버스
    대상 초등 ~ 중등 고등 +
    용도 하드웨어 순차 제어 AI 파이프라인 + 하드웨어 통합
