    첫 실행¶

    설치 후 처음 프리모스튜디오 앱을 실행합니다. 첫 실행에는 운영체제 보안 알림이 한 번 등장합니다.

    무엇을 하는 단계인가요?¶

    • 운영체제 보안 알림 (Defender / Gatekeeper) 한 번 허용 — 처음 한 번만 필요
    • 백엔드 자동 시작 확인 — 앱 내부에서 자동 진행되며 보통 5~10초 소요
    • 정상 시작되면 키트 선택 화면이 표시됩니다 (다음 페이지)

    다음 실행부터는 자동

    아래 보안 알림 절차는 첫 실행 한 번만 필요합니다. 시스템이 신뢰 목록에 추가하면 다음부터는 일반 더블 클릭으로 바로 실행됩니다.

    절차¶

    macOS¶

    1. 응용 프로그램 폴더에서 프리모스튜디오 더블 클릭
    2. (첫 실행만) "확인되지 않은 개발자" 안내 처리
      • macOS 가 다음 메시지를 표시합니다:

        "PrimoStudio"는 확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다.

      • 시스템 설정 → 개인정보 보호 및 보안 으로 이동
      • 화면 아래쪽 "PrimoStudio이(가) 확인되지 않은 개발자가 배포했기 때문에..." 메시지 옆 [확인 없이 열기] 클릭
      • 비밀번호 입력
    3. 앱 창이 표시되기까지 5~10초 대기
    4. 키트 선택 화면이 나타나면 정상 — 키트 선택 으로 이동

    확인 없이 열기 버튼 위치

    시스템 설정 → 개인정보 보호 및 보안 화면을 아래쪽으로 스크롤 하면 보안 메시지가 보입니다. 화면 가운데가 아니라 화면 하단에 위치합니다.

    Windows¶

    1. 시작 메뉴 또는 바탕화면 단축아이콘 으로 프리모스튜디오 실행
    2. (첫 실행만) Windows Defender SmartScreen 처리
      • Defender 가 다음 메시지를 표시합니다:

        "Windows의 PC 보호 — Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다."

      • [추가 정보] 클릭
      • 나타난 [실행] 버튼 클릭
    3. 앱 창이 표시되기까지 5~10초 대기
    4. 키트 선택 화면이 나타나면 정상 — 키트 선택 으로 이동

    자동 업데이트¶

    새 버전이 나오면 앱 상단에 알림 배너가 표시됩니다:

    새 버전 v2.3.XX 사용 가능   [변경 내용] [나중에] [업데이트]
    • [변경 내용] — 무엇이 바뀌었는지 미리 확인
    • [나중에] — 다음 실행 시 다시 알림
    • [업데이트] — 다운로드 시작 → 다운로드 완료 후 [지금 재시작] 버튼 표시

    수업 중 자동 재시작 없음

    수업 중 갑자기 재시작되는 일은 없습니다 — 사용자가 [업데이트] 와 [지금 재시작] 버튼을 명시적으로 눌러야만 진행됩니다.

    자주 발생하는 문제¶

    백엔드 서버 시작 실패 다이얼로그

    가장 흔한 첫 실행 문제입니다. 다음 메시지가 표시됩니다:

    백엔드 서버 시작 실패
    프리모스튜디오 백엔드 서버가 시작되지 않았습니다.

    확인할 사항:
    1. Windows Defender 또는 보안 프로그램 알림이 떴다면 "허용"을 클릭해 주세요.
    2. 위 안내가 없으면 앱을 우클릭 → "관리자 권한으로 실행"을 한 번 시도해 주세요.
    3. 한 번 정상 실행되면 그 후에는 일반 실행으로도 동작합니다.

    해결 순서:

    1. 화면 우하단 알림 영역에 Defender 알림이 있는지 확인 → 있으면 [허용]
    2. 알림이 없으면 앱 아이콘 우클릭 → [관리자 권한으로 실행] 한 번 시도
    3. 한 번 정상 실행 후 일반 더블 클릭으로 다시 실행
    키트 선택 화면이 나타나지 않음 (30초 이상 검은 화면)

    이전 실행이 비정상 종료된 경우 백엔드 프로세스 (Python) 가 메모리에 남아있을 수 있습니다.

    Windows:

    • Ctrl+Shift+Esc 로 작업 관리자 열기
    • "프로세스" 탭에서 python.exe 또는 Python 항목을 모두 종료
    • 프리모스튜디오 다시 실행

    macOS:

    • Cmd+Space → "활동 모니터" 검색하여 실행
    • "CPU" 탭에서 python 또는 python3.13 검색
    • 항목 선택 후 좌상단 ✕ 버튼 → "종료"
    • 프리모스튜디오 다시 실행

    자동 정리 기능

    프리모스튜디오 v2.3.x 부터는 앱 시작 시 좀비 프로세스를 자동 정리합니다. 그래도 위 증상이 발생하면 페이지 하단 📮 피드백 보내기 로 알려주세요.

    강사 팁¶

    첫 실행은 한 번만 까다로움

    두 번째 실행부터는 바로 메인 화면이 뜹니다. 학생들이 첫 실행에 막히면 옆에서 한 번만 도와주면 됩니다.

    Defender 알림은 정상 동작

    프리모스튜디오 자체 문제가 아닙니다. 운영체제 표준 동작이고, 한 번 허용하면 영구적으로 신뢰됩니다.

    수업 시작 5분 전 일괄 첫 실행

    학생들 PC 모두 한 번 켜서 첫 실행을 마쳐두면 수업 시간 손실이 없습니다.

    수업 중 업데이트 알림 처리

    자동 업데이트 알림이 떠도 수업 중에는 [나중에] 권장. 업데이트 후엔 흐름 호환성 확인이 필요할 수 있습니다.

    다음 단계¶

    키트 선택 화면이 표시되면 키트 선택 → 으로 이동합니다.
