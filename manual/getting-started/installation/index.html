    설치하기¶

    프리모스튜디오 앱을 PC 에 설치합니다.

    무엇을 하는 단계인가요?¶

    primolabs.kr 에서 본인 PC 에 맞는 설치 파일을 받아 실행합니다. 설치 후엔 첫 실행 으로 이동합니다.

    다운로드 파일 선택¶

    primolabs.kr → 다운로드 에서 PC 에 맞는 파일을 받습니다.

    운영체제 파일 어떤 PC 인가요?
    macOS (Apple Silicon) PrimoStudio-x.y.z-arm64.dmg 2020년 이후 출시 Mac (M1·M2·M3·M4 칩)
    macOS (Intel) PrimoStudio-x.y.z-x64.dmg 2019년 이전 출시 Mac (Intel 칩)
    Windows (64-bit) PrimoStudio-x.y.z-setup.exe Windows 10·11 64비트

    Mac 칩 종류 확인

    화면 좌상단 사과 아이콘 → "이 Mac 에 관하여" → "칩" 항목 확인:

    • "Apple M1/M2/M3/M4" 표시 → Apple Silicon (arm64.dmg)
    • "Intel" 표시 → Intel (x64.dmg)

    절차¶

    macOS¶

    1. DMG 파일 더블 클릭 — Finder 에서 다운로드 받은 PrimoStudio-x.y.z-arm64.dmg (또는 -x64.dmg) 파일을 더블 클릭합니다.
    2. 응용 프로그램 폴더로 드래그 — 열린 창에서 프리모스튜디오 아이콘을 옆의 "Applications" 폴더로 끌어다 놓습니다.
    3. DMG 추출 안전 종료 — Finder 사이드바에서 마운트된 DMG 옆 ⏏ 아이콘을 눌러 추출합니다.
    4. 설치 완료. 첫 실행 페이지로 이동합니다.

    Windows¶

    1. PrimoStudio-x.y.z-setup.exe 더블 클릭
      • "관리자 권한으로 실행" 을 쓰지 마세요. 그냥 더블 클릭하면 됩니다.

    2. 설치 폴더 화면 — 기본 경로 그대로 [설치]

      • 화면에 이런 경로가 이미 채워져 있습니다:
      C:\Users\<사용자>\AppData\Local\Programs\primolabs
      • 그대로 두고 넘어가시면 됩니다. 바꿔야 할 사정이 있다면 아래 "다른 위치에 설치해야 한다면" 을 먼저 읽어 주세요.
      • [설치 완료] 클릭
      • 시작 메뉴 또는 바탕화면에 "PrimoStudio" 아이콘 생성 확인. 첫 실행 페이지로 이동합니다.

    C:\Program Files\ 에 설치하면 안 됩니다

    다른 프로그램이 대부분 C:\Program Files\ 에 설치되기 때문에 거기가 맞는 자리처럼 느껴집니다. 프리모스튜디오는 다릅니다. 그 폴더는 Windows 가 일반 권한으로 쓰지 못하게 막아 두는데, 프리모스튜디오는 실행 중에 자기 폴더에 파일을 씁니다.

    거기에 설치하면 이렇게 됩니다:

    증상 언제 나타나나
    ▶ 시작을 눌러도 카드가 한 장도 안 돌고 [WinError 5] 액세스가 거부되었습니다 오류 바로
    자동 업데이트가 반쯤만 적용됨 — 화면은 새 버전인데 내부는 옛 버전이라 카메라·로봇 명령이 조용히 안 먹음 업데이트 몇 번 뒤

    설치 프로그램이 경로 변경을 막지는 않습니다. 기본값이 이미 옳으니 그냥 두고 넘어가시면 됩니다.

    다른 위치에 설치해야 한다면 (Windows)¶

    학교 정책상 특정 드라이브에 깔아야 하는 경우가 있습니다. 경로를 바꿔도 됩니다 — 지켜야 할 조건은 하나뿐입니다.

    로그인한 계정이 관리자 권한 없이 쓸 수 있는 폴더여야 합니다.

    프리모스튜디오는 자동 업데이트할 때 자기 폴더의 파일을 교체하고, 실행 중에도 자기 폴더에 파일을 씁니다. 그래서 그 폴더에 쓰지 못하면 둘 다 막힙니다.

    경로 가능 여부
    C:\Users\<사용자>\AppData\Local\Programs\primolabs (기본값) ✅ 권장
    D:\PrimoStudio 처럼 내가 만든 폴더 ✅ 쓰기 권한이 있으면 가능
    C:\Program Files\ · C:\Program Files (x86)\ ❌ 관리자 전용
    C:\Windows\ 및 그 하위 ❌ 관리자 전용

    고른 폴더가 괜찮은지 미리 확인하는 법

    파일 탐색기로 그 폴더에 들어가 우클릭 → [새로 만들기] → [텍스트 문서] 를 만들어 봅니다. 권한 확인 창 없이 만들어지면 괜찮습니다 (만든 파일은 지우세요).

    관리자 권한이 필요 없습니다

    기본 경로(사용자 영역)에 설치하면 UAC 확인 창도 뜨지 않고, 이후 자동 업데이트도 관리자 권한 없이 동작합니다. 학교 PC 에서 관리자 계정을 못 쓰는 환경도 그대로 설치됩니다.

    반대로 "관리자 권한으로 실행" 으로 설치 프로그램을 띄우면 C:\Program Files\ 를 고를 수 있게 되어 위 문제로 이어질 수 있습니다.

    자동 업데이트¶

    설치 후엔 새 버전이 나올 때마다 앱이 자동으로 알림을 보여줍니다 (자세한 사용법은 첫 실행 → 자동 업데이트 참조).

    수업 중 갑자기 재시작 없음

    사용자가 [업데이트] 버튼을 눌러야만 다운로드·재시작이 진행되므로 수업 중 갑자기 앱이 재시작되는 일은 없습니다.

    오래된 버전은 알림을 받지 못합니다 — 한 번만 수동 설치

    아래 두 구간에 해당하면 자동 업데이트 알림이 오지 않습니다. 지금 쓰는 버전을 [설정] 탭 → 앱 정보에서 확인해 주세요 ([업데이트 확인] 버튼 사용법은 첫 실행 → 지금 최신인지 직접 확인하기).

    지금 버전 왜 할 일
    v2.3.x 이하 (구 FACTO Works / FactoStudio) 앱 이름이 바뀌면서 예전 버전과 연결이 끊겼습니다 primolabs.kr 에서 최신 파일을 받아 한 번 설치
    v2.6.1 · v2.6.2 (macOS 만) 이 두 버전은 macOS 가 업데이트를 받지 못하게 막습니다 위와 동일하게 한 번 수동 설치

    한 번만 하면 됩니다. 설치 후 기존 설정·저장한 위치·흐름은 그대로 남고, 이후부터는 자동 업데이트가 정상 동작합니다.

    자주 발생하는 문제¶

    잘못된 형식의 파일 / 손상된 항목 (macOS)

    다운로드가 중단됐을 가능성이 높습니다. DMG 파일을 삭제하고 primolabs.kr 에서 다시 받아주세요. 그래도 동일한 문제가 발생하면 페이지 하단 📮 피드백 보내기 로 알려주세요.

    이미 C:\Program Files\ 에 설치했어요 (Windows)

    앱이 스스로 감지해서 첫 실행 때 한 번 알려 줍니다:

    ⚠️ 시스템 영역 설치 감지
    프리모스튜디오가 시스템 영역에 설치되어 있습니다.
    현재 설치 경로: C:\Program Files\...

    시스템 영역 설치본은 자동 업데이트가 부분적으로 실패할 수 있어,
    시간이 지나면 일부 기능이 정상 동작하지 않을 수 있습니다.
    (예: 카드 프로그램 ▶ 시작 무반응, 카메라 명령 미반응 등)

    내 설치 위치 확인하기 — 시작 메뉴에서 PrimoStudio 아이콘 우클릭 → [파일 위치 열기] → 주소창 확인. Program Files 가 보이면 해당됩니다.

    고치는 법:

    1. 설정 → 앱 → PrimoStudio → 제거
    2. primolabs.kr 에서 설치 파일을 받아 관리자 권한 없이 다시 실행
    3. 설치 폴더 화면에서 경로를 그대로 두고 [설치]

    저장하신 카드 프로그램·교시 위치·설정은 그대로 보존됩니다. 제거해도 지워지지 않는 별도 폴더에 있습니다.

    Apple Silicon Mac 인데 Intel 버전을 받았어요

    심각한 문제는 아니지만 (Rosetta 로 동작) 성능이 절반 정도로 떨어집니다. 응용 프로그램 폴더에서 프리모스튜디오를 제거하고 arm64.dmg 를 다시 받아주세요.

    강사 팁¶

    다운로드 사전 준비

    학생 PC 일괄 설치 시 USB 메모리에 미리 받아두면 학교 와이파이 부하 없이 빠르게 설치할 수 있습니다.

    일괄 설치할 때 가장 자주 나는 실수 — 설치 위치

    여러 대를 빠르게 돌리다 보면 설치 폴더 화면을 습관적으로 넘기다가 C:\Program Files\ 로 바꿔 놓기 쉽습니다. 한 대만 잘못돼도 그 PC 는 수업 중에 ▶ 시작이 안 됩니다.

    일괄 설치 후 한 번에 확인하는 법 — 각 PC 에서 시작 메뉴의 PrimoStudio 아이콘 우클릭 → [파일 위치 열기] → 주소창을 봅니다. Program Files 가 보이면 잘못된 것이고, 기본 경로(AppData\Local\Programs\primolabs) 또는 의도적으로 지정한 폴더 면 정상입니다.

    설치 관리자 계정으로 일괄 작업하시더라도 설치 프로그램만은 관리자 권한으로 띄우지 마세요.

    Mac 칩 확인을 헷갈려하는 학생

    사과 아이콘 → "이 Mac 에 관하여" 화면을 함께 보여주는 게 가장 빠릅니다.

    시뮬레이터로 미리 체험

    학생이 본인 PC 에 설치를 못 했어도 메뉴얼만 미리 읽어두게 하면 첫 수업 진행이 부드럽습니다.

    다음 단계¶

    설치가 완료되면 첫 실행 → 으로 이동합니다.

    이 페이지에 빠진 내용이나 잘못된 부분을 발견하시면 페이지 하단 📮 피드백 보내기 를 활용해 주세요.

    📮 이 페이지에 대한 의견이 있으신가요?

    오류 제보, 개선 제안, 질문 모두 환영합니다. 강사·운영자가 직접 검토합니다.
