    시작하기¶

    프리모스튜디오를 처음 사용하기 위한 준비 단계입니다. 아래 3단계를 순서대로 진행하면 메인 화면까지 도달할 수 있습니다.

    진행 순서¶

    • 1. 설치하기

      macOS · Windows 별 앱 설치

      설치하기로 이동

    • 2. 첫 실행

      첫 실행 시 보안 알림 안내, 백엔드 자동 시작 확인

      첫 실행으로 이동

    • 3. 키트 선택

      사용할 하드웨어 키트 선택 (또는 시뮬레이터 모드)

      키트 선택으로 이동

    전체 소요 시간: 약 5~10분

    실행 환경 권장 사양¶

    항목 권장 사양 비고
    운영체제 macOS 12+ / Windows 10+ macOS 는 Apple Silicon · Intel 모두 지원
    메모리 8GB 이상 AI 비전 사용 시 16GB 권장
    디스크 여유 2GB 이상 설치 + 모델 캐시 포함
    네트워크 카메라·로봇과 같은 Wi-Fi 또는 유선 LAN 같은 네트워크에 있어야 자동 발견
    인터넷 첫 다운로드와 자동 업데이트 시에만 평상 사용 시 오프라인 가능

    강사 팁¶

    • 첫 사용 안내는 키트 선택 화면까지 — 학생이 메인 화면으로 진입한 뒤에는 하드웨어 연결 단계로 넘어가는 게 자연스럽습니다.
    • 시뮬레이터 모드를 먼저 권장 — 하드웨어 없이도 모든 기능 학습 가능. 익숙해진 후 실제 키트로 전환하면 시행착오를 크게 줄일 수 있습니다.
    • 학생 PC 일괄 설치 시 다운로드 링크보다 USB 메모리에 미리 받아두는 것이 빠릅니다.
