    컨베이어 연결¶

    컨베이어를 PC 와 연결하고 전원을 켭니다.

    무엇을 하는 단계인가요?¶

    컨베이어 박스 (컨베이어 + 센서 일체) 를 USB 케이블로 PC 에 연결하고, 전용 어댑터를 콘센트에 꽂아 전원을 인가합니다. 앱이 자동으로 컨베이어를 인식하고 펌웨어 버전을 표시합니다.

    절차¶

    1. 전원 어댑터 연결 — 컨베이어 박스의 전용 어댑터를 콘센트에 꽂습니다. 컨베이어 LED 가 켜지면 정상.
    2. USB 케이블 연결 — 컨베이어 박스에 동봉된 USB 케이블을 PC 에 연결합니다.
    3. 앱에서 [장비] 탭 열기 — 화면 상단의 [장비] 탭을 클릭합니다.
    4. 컨베이어 섹션 확인 — 포트 드롭다운에 자동으로 USB 포트가 표시됩니다 (예: [COM3] — USB Serial Device).
      • 표시 안 되면 옆의 🔍 (검색) 버튼을 한 번 클릭해서 다시 스캔합니다.
    5. 포트 선택 + [연결] 클릭 — 드롭다운에서 컨베이어 포트를 선택하고 [연결] 버튼을 누릅니다.
    6. 연결 확인 — 상태 표시가 회색 "● 미연결" 에서 초록색 "● 연결됨" 으로 변경됩니다.
    7. 펌웨어 버전 자동 표시 — 화면 어딘가에 컨베이어 펌웨어 버전이 자동으로 표시됩니다 (예: "컨베이어 v5.5").

    펌웨어 업데이트¶

    새 펌웨어 버전이 있으면 앱이 자동으로 알림을 표시합니다.

    1. 펌웨어 패널에 "업데이트 있음" 주황 배지가 표시됩니다.
    2. 패널을 펼쳐 "⚡ USB 플래싱" 버튼 클릭
    3. 확인 대화상자: "컨베이어 펌웨어를 USB로 업데이트합니다. 진행 중 USB를 분리하지 마세요." → [확인]
    4. 진행률 바 (0% → 100%) 가 표시되며, 완료 시 ✓ 표시

    USB 분리 절대 금지

    펌웨어 업데이트 진행 중에 USB 케이블을 분리하면 펌웨어 손상으로 컨베이어를 사용할 수 없게 됩니다. 진행률 100% 와 "✓ 플래싱 완료" 메시지를 반드시 확인 후에 분리하세요.

    자주 발생하는 문제¶

    포트 드롭다운에 아무것도 안 보임
    1. 🔍 (검색) 버튼을 한 번 클릭해서 다시 스캔
    2. USB 케이블이 PC 와 컨베이어 양쪽 모두 단단히 연결됐는지 확인
    3. 다른 USB 포트 시도 (특히 PC 앞면 포트가 인식 잘 안 되는 경우 뒷면 포트)
    4. USB 케이블 자체 문제 의심 — 다른 케이블로 교체 시도
    컨베이어 연결 실패: COM3
    1. 컨베이어 전원이 켜져 있는지 확인 (LED)
    2. 다른 앱이 같은 포트를 점유 중인지 확인 (Arduino IDE, 시리얼 모니터 등을 모두 종료)
    3. 앱을 완전 종료 후 재실행
    4. 그래도 동작하지 않으면 USB 케이블을 분리·재연결 후 다시 시도
    펌웨어 버전이 '확인 불가' 로 표시됨

    옛 펌웨어가 설치된 경우입니다. 펌웨어 업데이트 패널의 USB 플래싱으로 최신 버전으로 갱신해 주세요.

    한 번 정상 인식됐다가 갑자기 끊김

    USB 케이블의 접촉 불량 또는 케이블 자체 문제일 가능성이 높습니다. 케이블 교체로 대부분 해결됩니다.

    강사 팁¶

    첫 사용 안내

    학생이 [연결] 버튼을 눌러서 "● 연결됨" 표시를 확인하면 다음 단계로 넘어가세요. 보통 5초 안에 연결됩니다.

    USB 포트 자리 고정

    같은 PC 에서 매번 다른 포트를 사용하면 Windows 가 매번 새 포트로 인식 (COM3 → COM4 → COM5 ...). 가능하면 항상 같은 포트 사용 권장.

    수업 종료 시

    컨베이어는 USB 분리해도 펌웨어/설정이 유지됩니다. 수업 종료 시 USB 분리는 자유롭게 하셔도 됩니다.

    다음 단계¶
