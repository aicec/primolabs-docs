    문제 해결¶

    자주 발생하는 하드웨어 연결 문제와 해결 방법.

    무엇을 다루나요?¶

    연결이 안 되거나 동작이 이상할 때 가장 먼저 시도해 볼 항목들입니다. 각 문제별 단계를 따라가도 해결되지 않으면 페이지 하단 📮 피드백 보내기 로 알려주세요.

    컨베이어 / 카메라 USB 인식 안 됨

    증상: [장비] 탭의 포트 드롭다운에 USB 가 보이지 않음

    순서 시도할 것
    1 드롭다운 옆 🔍 (검색) 버튼 클릭하여 다시 스캔
    2 컨베이어/카메라의 전원이 켜져 있는지 확인
    3 USB 케이블이 PC 와 장비 양쪽 모두 단단히 연결됐는지 확인
    4 다른 USB 포트 시도 (PC 앞면 → 뒷면)
    5 USB 케이블 자체 문제 의심 — 다른 케이블로 교체
    6 Arduino IDE / 시리얼 모니터 등 같은 포트를 점유하는 다른 앱 종료
    7 앱 완전 종료 후 재실행
    컨베이어 또는 카메라 연결 직후 끊김

    증상: "● 연결됨" → 잠시 후 "● 미연결" 또는 "● 응답 없음"

    • USB 케이블의 접촉 불량 또는 케이블 자체 문제일 가능성 높음
    • 다른 USB 케이블로 교체
    카메라 영상이 안 나옴

    증상: 카메라 패널에 영상이 표시되지 않음

    모드 확인 사항
    USB 직결 위 "USB 인식 안 됨" 절차 진행
    Wi-Fi 모드 카메라와 PC 가 같은 Wi-Fi 네트워크에 있는지 확인 (같은 SSID 라도 라우터가 여러 대일 수 있음)
    Wi-Fi 모드 카메라 IP 가 입력란에 정확히 입력됐는지 확인
    Wi-Fi 모드 카메라 위치 — 라우터에서 멀면 신호 약해 끊김

    자세한 내용은 카메라 연결 → 자주 발생하는 문제 참조.

    카메라 Wi-Fi 설정이 안 됨 (SSID·비밀번호 저장 실패)

    카메라를 USB 로 연결한 뒤 Wi-Fi 정보를 저장하려는데 실패한다면, 에러 메시지에 따라 원인이 다릅니다. 메시지가 바뀌면 다음 단계로 넘어간 것이니 진전입니다.

    에러 메시지 원인 해결
    응답 없음: WIFI_SET USB 절전 모드가 포트를 잠재움 (액세스 거부) (Windows) 장치 관리자 → USB 허브 → 선택적 절전 모드 끄기. USB 케이블 재연결 후 다시 시도
    응답 시간 초과 (30초) 5GHz Wi-Fi 에 연결하려 함 카메라는 2.4GHz 전용입니다. 2.4GHz SSID 를 선택해 다시 저장

    카메라는 2.4GHz Wi-Fi 만 됩니다

    현장 공유기가 5GHz 와 2.4GHz 를 같은 이름(SSID) 으로 쓰는 경우가 많습니다. 이때 카메라가 5GHz 에 붙으려다 실패합니다. 공유기 설정에서 2.4GHz 를 별도 이름으로 나누거나, 2.4GHz 전용 SSID 를 선택하세요.

    USB 직결로 먼저 사용 가능

    Wi-Fi 설정이 급하지 않다면, 카메라는 USB 직결만으로도 영상·AI 비전이 정상 동작합니다. Wi-Fi 는 카메라를 로봇 근처에 자유롭게 둘 때만 필요합니다.

    로봇 연결 실패

    증상: "로봇 #1: 연결 실패" 에러

    순서 시도할 것
    1 로봇 본체에 표시된 IP 가 입력한 IP 와 일치하는지 확인
    2 로봇 부팅 완료 대기 (전원 인가 후 30~60초)
    3 PC 와 로봇이 같은 네트워크에 있는지 확인 (같은 공유기)
    4 PC 명령 프롬프트에서 ping 192.168.1.xxx (실제 로봇 IP) 시도 → 응답 없으면 네트워크 문제
    5 LAN 케이블 양쪽 모두 단단히 연결됐는지 확인
    6 로봇 전용 어댑터가 콘센트에 정상 연결됐는지 확인

    자세한 내용은 Lite 6 로봇팔 연결 → 자주 발생하는 문제 참조.

    로봇팔이 명령에 반응하지 않음 (Z 좌표 등)

    가장 흔한 원인: 작업 범위 밖 좌표 (특히 Z=50mm 미만)

    Lite 6 로봇팔 연결 → 작업 범위 섹션 참조 — Z=50mm 가 안전을 위한 의도된 최솟값입니다.

    컨베이어가 동작 안 함

    증상: [벨트 출발] 카드를 실행해도 컨베이어가 돌지 않음

    순서 확인 사항
    1 [장비] 탭의 컨베이어 상태가 "● 연결됨" 인지 확인
    2 컨베이어 전용 어댑터가 콘센트에 정상 연결됐는지 확인
    3 컨베이어 위에 장애물이 있는지 확인
    4 카드의 속도 설정이 너무 낮지 않은지 확인 (1단계는 매우 느림)
    센서가 반응 안 함

    증상: 물체를 센서 앞에 두어도 카드가 진행되지 않음

    순서 확인 사항
    1 컨베이어 연결 상태 확인 (위와 동일)
    2 센서 앞에 손가락을 천천히 가까이 가져다 대 보기 (반응하면 정상)
    3 카드에서 어느 센서 (IR1/IR2) 를 대기하는지 확인
    4 센서 표면에 먼지나 이물질이 묻어 있는지 확인
    펌웨어 업데이트 실패

    증상: USB 플래싱 진행 중 에러 또는 빨간 X 표시

    순서 시도할 것
    1 진행 중 USB 케이블 분리하지 않았는지 확인
    2 다른 앱이 같은 포트를 점유 중이지 않은지 확인
    3 컨베이어/카메라 전원 재인가 후 다시 시도
    4 다른 USB 포트로 변경 후 다시 시도
    USB 케이블 매핑 오류 경고

    증상: 펌웨어 업데이트 시 "컨베이어 슬롯에 다른 장비가 연결되어 있습니다" 같은 경고

    컨베이어와 카메라의 USB 케이블이 바뀌어 연결됐을 가능성. 두 케이블의 연결 위치를 확인하고, 올바른 장비에 연결된 상태에서 다시 시도하세요.

    안전 차단

    잘못된 장비에 펌웨어가 쓰여지지 않도록 자동 차단되는 정상 동작입니다. 장비 손상 방지를 위한 안전 장치입니다.

    전체 재시작 (가장 단순한 해결법)¶

    위 항목으로 해결되지 않으면 다음 순서로 전체 재시작:

    1. 앱 완전 종료 (작업 표시줄에서 우클릭 → 종료)
    2. 모든 USB 케이블 분리 (컨베이어, 카메라)
    3. 모든 전원 어댑터 분리 (컨베이어, 로봇)
    4. 5초 대기
    5. 전원 어댑터 재연결 → USB 케이블 재연결
    6. 앱 재실행
    7. [장비] 탭에서 다시 연결

    전체 재시작은 해결률 80%

    경험상 USB / 네트워크 / 앱 상태 관련 문제의 80% 정도가 전체 재시작으로 해결됩니다. 복잡한 진단 전에 한 번 시도해 보는 것이 시간을 아낍니다.

    도움이 더 필요할 때¶

    피드백 보낼 때 함께 알려주시면 좋은 정보

    1. 사용 중인 키트 종류 (예: Lite 6 로봇팔 + 컨베이어)
    2. 앱 버전 (도움말 메뉴 또는 자동 업데이트 패널에서 확인)
    3. 정확한 오류 메시지 (가능하면 캡처)
    4. 어느 단계에서 막혔는지 (예: "USB 연결까지는 됐지만 펌웨어 버전이 표시 안 됨")
    5. 운영체제 (macOS / Windows)
