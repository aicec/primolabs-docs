    카메라 연결¶

    카메라를 PC 와 연결합니다. USB 직결 또는 Wi-Fi 연결 두 가지 모드를 지원합니다.

    무엇을 하는 단계인가요?¶

    카메라를 PC 와 연결하여 영상 스트리밍을 받습니다. 처음 사용 시에는 USB 직결을 권장합니다 (가장 안정적이고, Wi-Fi 설정도 USB 를 통해 합니다).

    권장 첫 사용 흐름

    USB 직결 → Wi-Fi 설정 입력 (선택) → 무선 사용 가능

    USB 직결만으로도 모든 기능 사용 가능합니다. Wi-Fi 모드는 카메라를 PC 에서 떨어뜨려 두고 싶을 때 사용합니다.

    USB 직결 (가장 안정적)¶

    1. USB 케이블 연결 — 카메라의 USB 포트와 PC 를 USB 케이블로 연결합니다.
    2. 앱에서 [장비] 탭 열기
    3. 카메라 USB 섹션 확인 — 포트 드롭다운에 USB 포트가 자동 표시됩니다 (예: [COM4] — USB Serial Device).
      • 표시 안 되면 🔍 (검색) 버튼 클릭
    4. 포트 선택 + [연결] 클릭 — 연결 성공 시 "● 연결됨" 표시
    5. 펌웨어 버전 자동 표시 — 화면에 카메라 펌웨어 버전이 표시됩니다 (예: "카메라 v1.12")

    Wi-Fi 연결 (USB 직결 이후 설정)¶

    USB 로 카메라를 연결한 상태에서 다음 절차로 Wi-Fi 정보를 카메라에 저장합니다.

    1단계 — Wi-Fi 정보 카메라에 저장¶

    1. [장비] 탭 → 카메라 USB 섹션 → "▶ 카메라 Wi-Fi 설정" 클릭하여 펼칩니다.
    2. SSID 입력 — 카메라가 연결될 Wi-Fi 이름. PC 가 사용 중인 같은 Wi-Fi 권장.
    3. 비밀번호 입력 — 👁️ 토글로 표시/숨김 전환 가능
    4. [Wi-Fi 설정 전송] 클릭
    5. 진행 상태가 순서대로 표시됩니다:
      • "⏳ Wi-Fi 설정 전송 중..."
      • "📡 카메라가 Wi-Fi 에 접속하는 중..."
      • "✅ 카메라 연결 완료! IP: 192.168.x.x" ← 1단계 완료

    2단계 — 자동으로 채워진 IP 로 스트리밍 연결¶

    Wi-Fi 설정이 완료되면 카메라 스트리밍 섹션의 IP 입력란에 받은 IP 가 자동으로 채워집니다.

    자동 채움 안내

    "🟢 자동 감지된 IP: 192.168.x.x" 안내가 카메라 스트리밍 섹션에 표시됩니다. 사용자가 IP 를 직접 입력할 필요 없습니다.

    1. 카메라 스트리밍 섹션 으로 스크롤 (같은 [장비] 탭 안에 있음)
    2. IP 가 자동 채워진 것을 확인
    3. [연결] 버튼 클릭
    4. 영상 스트리밍이 시작되면 무선 사용 준비 완료

    USB 케이블 분리 가능

    Wi-Fi 스트리밍 연결이 정상이면 카메라 USB 케이블을 분리해도 카메라가 Wi-Fi 로 자동 동작합니다. 카메라를 자유롭게 위치시킬 수 있습니다.

    카메라 스트리밍 (수동 IP 입력)¶

    USB 직결 없이 처음부터 IP 를 알고 있는 경우 (예: 이전에 설정해둔 카메라 재사용):

    1. [장비] 탭 → 카메라 스트리밍 섹션
    2. IP 입력란에 카메라 IP 직접 입력
    3. [연결] 버튼 클릭

    최근 사용 IP 자동 기억

    자주 쓰는 IP 는 자동으로 기억됩니다. 다음 실행 시 클릭만으로 재연결 가능합니다.

    Wi-Fi 변경 (다른 장소에서 사용)¶

    학교가 아닌 다른 장소에서 사용하려면 Wi-Fi 정보를 다시 입력해야 합니다.

    1. 카메라를 USB 로 PC 에 연결
    2. 위 Wi-Fi 연결 → 1단계 절차를 새 SSID/비밀번호로 다시 진행
    3. 카메라가 새 Wi-Fi 에 자동 접속 (이전 설정 덮어씀)
    4. 2단계 의 자동 채움 IP 로 다시 [연결]

    자주 발생하는 문제¶

    USB 포트 드롭다운에 안 보임

    컨베이어 연결 → 자주 발생하는 문제 와 동일한 절차로 해결됩니다 (검색 버튼, 다른 USB 포트, 케이블 교체).

    Wi-Fi SSID를 입력해주세요

    SSID 입력란이 비어있습니다. Wi-Fi 이름을 입력 후 다시 시도하세요.

    카메라 USB 연결이 필요합니다

    Wi-Fi 설정 전송은 카메라가 USB 로 연결된 상태에서만 가능합니다. [장비] 탭에서 카메라를 USB 로 먼저 연결한 후 다시 시도하세요.

    카메라 펌웨어가 Wi-Fi 변경을 지원하지 않습니다

    옛 펌웨어 (v1.3 미만) 가 설치되어 있습니다. 펌웨어 업데이트 패널의 USB 플래싱으로 최신 버전으로 갱신 후 다시 시도하세요.

    Wi-Fi 변경 후 카메라 응답 없음 (30초)

    원인 1: SSID/비밀번호가 잘못 입력됨 → 정확한지 다시 확인 후 재시도

    원인 2: 카메라가 Wi-Fi 신호 범위 밖에 있음 → 카메라를 라우터 가까이 (5m 이내) 두고 재시도

    다른 Wi-Fi 네트워크에 있습니다 (서브넷 미스매치)

    PC 와 카메라가 다른 Wi-Fi 네트워크에 연결됐다는 뜻입니다. 같은 학교 안에서 SSID 가 같아도 라우터가 여러 대 있는 환경에서 발생할 수 있습니다.

    해결: 카메라를 PC 가까이 (1m 이내) 두고 다시 시도하거나, 학교 네트워크 관리자에게 mesh / repeater 설정을 확인 요청하세요.

    카메라 영상이 끊겼다 다시 연결됨 (응답 없음 (재연결 중...))

    카메라 Wi-Fi 신호가 약해졌을 가능성. 앱이 자동 재연결을 시도하므로 잠시 기다리면 다시 "● 연결됨" 으로 돌아갑니다. 자주 발생하면 카메라를 라우터 가까이 옮겨 주세요.

    강사 팁¶

    첫 사용은 USB 직결로

    Wi-Fi 모드는 익숙해진 후 추가 학습으로 진행. 첫 수업에는 USB 직결만으로 충분합니다.

    Wi-Fi 모드의 핵심

    카메라와 PC 가 반드시 같은 Wi-Fi (SSID 만 같은 게 아니라 같은 라우터) 에 연결되어 있어야 합니다. 학교에 라우터가 여러 대인 경우 mesh 설정이 안 되어 있으면 같은 SSID 라도 다른 네트워크일 수 있습니다.

    수업 환경 IP 자동 기억

    수업 환경에서 자주 쓰는 IP 는 입력란이 자동 기억하므로 학생이 매번 입력할 필요 없습니다.

    끊김 발생 시 즉시 해결법

    Wi-Fi 모드에서 카메라가 갑자기 끊기면 보통 신호 문제입니다. USB 직결로 전환하면 즉시 해결됩니다.
