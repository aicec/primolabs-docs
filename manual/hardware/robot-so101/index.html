    SO-101 서보 로봇팔 연결¶

    SO-101(SO-ARM101)은 서보 모터로 움직이는 5축 로봇팔 + 그리퍼입니다. so101_conveyor 키트에 들어 있으며, USB 케이블로 PC 에 바로 연결합니다.

    무엇을 하는 단계인가요?¶

    로봇팔을 PC 에 연결하고, 관절 영점(기준 자세)을 한 번 맞춰(캘리브레이션) 사용할 수 있게 준비하는 단계입니다. SO-101 은 처음 한 번 캘리브레이션을 해야 안전하게 움직입니다.

    SO-101 은 Lite 6 와 무엇이 다른가요?¶

    SO-101 Lite 6 (xArm)
    움직임 방식 관절만 (J1~J5) 관절 + 직교(X/Y/Z)
    연결 USB 케이블 유선 네트워크(TCP/IP)
    그리퍼 서보 (열림 정도 조절 가능) 열기/닫기 (이진)
    캘리브레이션 처음 1회 필수 공장 설정 사용

    관절 전용이란?

    SO-101 은 각 관절(J1~J5)의 각도로만 움직입니다. "손 끝을 (x, y, z) 좌표로 보내는" 직교 이동은 지원하지 않습니다. 그래서 카드·수동 제어가 자동으로 관절 모드로 나타납니다. 손끝 위치는 관절 각도로 정해집니다.

    graph LR
  A[J1 밑판 회전] --> B[J2 어깨]
  B --> C[J3 팔꿈치]
  C --> D[J4 손목 상하]
  D --> E[J5 손목 회전]
  E --> G[그리퍼 · 서보6]

    사전 준비¶

    • SO-101 팔로워(Follower) 로봇팔 + USB 케이블
    • 로봇팔 전용 전원 어댑터(6~12.6V) — 콘센트에 연결
    • 팔 주위 공간 확보 (움직일 때 부딪히지 않게)

    전원과 공간 먼저

    캘리브레이션·이동 중 팔이 크게 움직입니다. 주변 물건을 치우고, 로봇 전원 어댑터가 꽂혀 있는지 확인하세요.

    절차¶

    flowchart TD
  A[USB 케이블로 로봇팔 연결] --> B[앱 실행 → SO-101 키트 선택]
  B --> C[장비 탭에서 로봇 연결]
  C --> D{캘리브레이션<br/>되어 있나요?}
  D -- 아니오 --> E[관절 영점 캘리브레이션<br/>마법사 진행]
  D -- 예 --> F[사용 준비 완료]
  E --> F
    1. USB 케이블로 로봇팔(팔로워)을 PC 에 연결합니다.
    2. 앱을 실행하고 시작 화면에서 SO-101 키트를 선택합니다.
    3. [장비] 탭에서 로봇을 연결합니다. 연결되면 포트가 자동으로 인식됩니다.
    4. 처음이라면 관절 영점 캘리브레이션을 진행합니다(아래).

    캘리브레이션 전에는 움직이지 않습니다

    안전을 위해, 캘리브레이션이 안 된 로봇은 전원 이동을 거부합니다. 처음 1회 캘리브레이션을 반드시 완료하세요. 캘리브레이션 값은 로봇별로 저장되어 다음부터는 다시 하지 않아도 됩니다.

    관절 영점 캘리브레이션 (필수 · 처음 1회)¶

    [장비] 탭의 SO-101 캘리브레이션 마법사를 따라갑니다. 각 관절의 "기준 자세(영점)"를 로봇에게 알려주는 과정입니다.

    flowchart LR
  S[1. 기준 자세 잡기] --> J[2. 관절 하나씩<br/>영점 캡처]
  J --> G[3. 그리퍼<br/>열림/닫힘 캡처]
  G --> D[저장 완료]
    1. 기준 자세 — 로봇팔을 안내된 기본 자세로 맞춥니다.
    2. 관절 캡처 — J1~J5 를 하나씩 안내대로 맞추고 캡처합니다.
    3. 그리퍼 캡처 — 그리퍼를 열고/닫아 열림·닫힘 위치를 저장합니다.

    캘리브레이션은 강사가 시연 후 학생 체험

    처음엔 강사가 한 번 시연하고, 이후 학생이 마법사를 따라 하도록 하면 로봇의 "기준 자세" 개념을 자연스럽게 배웁니다.

    그리퍼 제어 (열림 정도 조절)¶

    SO-101 그리퍼는 서보라서 얼마나 열지(0~100%) 를 정할 수 있습니다.

    • [장비] 탭 그리퍼 섹션의 "열기 정도" 슬라이더로 원하는 % 를 먼저 설정합니다.
    • [N% 열기] 버튼을 누르면 그만큼 열립니다. [닫기], [정지] 도 있습니다.
    • 카드(프로그램)에서도 "그리퍼 열기" 카드에 열림 정도(%) 를 지정할 수 있습니다.

    물건 크기에 맞춰 열림 정도 조절

    작은 물건은 조금만, 큰 물건은 많이 열도록 % 를 조절하면 더 안정적으로 집을 수 있습니다.

    연속 조그 (누르는 동안 이동)¶

    수동 제어 패널의 관절 버튼(J1~J5)은 누르고 있는 동안 움직이고, 손을 떼면 즉시 멈춥니다.

    sequenceDiagram
  participant 사용자
  participant 로봇
  사용자->>로봇: 버튼 누름
  로봇-->>로봇: 계속 이동
  사용자->>로봇: 손 뗌
  로봇-->>로봇: 즉시 정지

    조금씩 정밀하게

    스텝 크기를 작게(1~2°) 두면 부드럽고 정밀하게 움직입니다.

    로봇 활성화 (비상정지 후 다시 쓰기)¶

    물리 비상정지(E-STOP) 버튼을 눌렀다 뗀 뒤에는 로봇이 멈춤 상태로 남습니다. 이때 수동 제어 패널의 [로봇 활성화] 버튼을 누르면(오류가 있으면 빨간색으로 안내됩니다) 오류를 지우고 모터를 다시 켜 바로 사용할 수 있습니다. (이 버튼은 움직이지 않고 준비만 시킵니다.)

    안전¶

    • 캘리브레이션 전에는 이동이 거부됩니다(안전장치).
    • 이동 전 주변 공간을 확보하고, 팔이 부딪히지 않도록 합니다.
    • 비상정지(E-STOP)는 항상 동작합니다. 누르면 즉시 멈춥니다.

    자주 발생하는 문제¶

    증상 확인할 점
    연결해도 움직이지 않음 캘리브레이션 완료 여부 확인(미완료 시 이동 거부)
    포트가 안 보임 USB 케이블 재연결 · 다른 USB 포트 · 로봇 전원 확인
    비상정지 후 반응 없음 물리 E-STOP 을 풀고 [로봇 활성화] 클릭
    그리퍼가 너무 많이 열림 열림 정도(%) 를 낮춰서 [N% 열기]

    강사 팁¶

    캘리브레이션 = 로봇의 '기준 잡기'

    캘리브레이션을 "로봇에게 똑바로 선 자세를 알려주는 것"으로 설명하면 학생이 이해하기 쉽습니다.

    관절로 생각하기

    SO-101 은 관절 각도로 움직입니다. "어깨를 얼마나, 팔꿈치를 얼마나" 처럼 관절 단위로 생각하도록 안내하세요.
